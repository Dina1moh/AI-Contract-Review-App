## CUAD Dataset

Download the CUAD v1 archive into `dataset/raw/cuad` with:

```powershell
python scripts\dataset\download_cuad.py
```

To overwrite an existing extraction:

```powershell
python scripts\dataset\download_cuad.py --force
```

The script uses the official CUAD Zenodo release:
https://zenodo.org/records/4595826/files/CUAD_v1.zip?download=1
